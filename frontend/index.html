How the score works. Each metric is min-max normalized across the funds shown (best = 1, worst = 0), flipped so higher is always better, multiplied by your weight, and summed to a 0–100 composite. Filter the set and it re-normalizes. Returns, Sharpe, Std Dev, AUM and TER come from Tickertape; Upside/Downside Capture are computed from AMFI NAV history against each category's index fund. Using one source keeps every fund comparable — different sites calculate these ratios differently. Data refreshes every 24 hours or on demand.
